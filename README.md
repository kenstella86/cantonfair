# Guangzhou Insider Guide

A free practical Guangzhou guide for buyers attending the Canton Fair. Built and deployed for Ken's sourcing business in the Pearl River Delta.

## What's inside

- Must-eat food categories (no specific restaurants — local tips only)
- Must-see attractions around Guangzhou
- Transport tips from airport to Pazhou Complex
- Survival Cantonese phrases
- WhatsApp CTA for sourcing enquiries (Guangzhou / Foshan / Shenzhen)

## Tech

- Single-file static site (one `index.html`, no build step)
- Mobile-first, responsive
- Color palette: deep teal `#0F4C5C`, terracotta `#E07A5F`, warm cream `#F5F1EA`

## Deploy

- **Framework preset**: None
